# Glossar

---
### Prädiktionen (*zu prädizieren / to predict*)
> Vorhersagen – das Schätzen oder Berechnen von zukünftigen oder unbekannten Werten basierend auf vorhandenen Daten von einem trainierten Modell.

### Merkmale (*features*)
> Sind die einzelnen Informationen oder Attribute, die aus den Rohdaten extrahiert werden, um ein ML-Modell zu trainieren. Sie beschreiben die Eigenschaften der Daten und helfen dem Modell, Muster zu erkennen.
